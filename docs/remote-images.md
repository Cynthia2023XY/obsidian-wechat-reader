# 公众号远程图片方案

采集只持久化净化正文、图片 ID 和经校验的 HTTPS 微信 CDN 来源；正文继续使用 asset: 占位，不采集图片二进制。阅读界面从文章资源映射取得地址，设置 no-referrer 和懒加载，失败显示查看原文提示。浏览器仍可能产生自身缓存。

接口公开已校验的图片来源，隐藏内部文件路径。旧版本文章同样映射到远程来源；本库正文缓存读取时合并索引中的来源。RSS 在可用时输出远程图片链接。没有合法远程地址的历史资源保留旧读取兼容。

归档仍由插件请求图片、检查 MIME 和 20 MiB 大小上限，再保存笔记库附件。远程图片归档不再写入公众号阅读图片缓存。普通 RSS 保留既有行为。

共享存储清理工具 scripts/clean-remote-images.py 默认预览；--apply 备份数据库、写清单、切换资源状态和只读快照，再删除能关联合法远程来源的 .img 文件。须在采集程序停止时使用。正文、无法恢复来源的图片和笔记库归档附件保留。

2026-11-05：清理 11,213 个文件、4,672,425,250 字节。数据库备份和文件清单位于共享数据目录。图片二进制已经删除，数据库备份只保留元数据；今后图片可用性依赖远程服务器。

验证：61 项插件测试、21 项采集集成测试通过；类型检查、插件构建、Node 26 内核封装和测试库部署通过。尚未在 Obsidian 中实际重载验证微信防盗链和远程显示。
