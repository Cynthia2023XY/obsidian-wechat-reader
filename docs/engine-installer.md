# 可选公众号引擎安装器

此功能随插件 1.1.0 发布；下载固定 1.0.0 引擎包，不修改旧版 Release 附件或 Tag。

## 用户流程

RSS/Atom 安装即用。设置和侧栏菜单均提供安装入口，启用公众号但缺少引擎时打开安装说明。确认前展示版本、GitHub 来源、下载量与目标位置；明确确认后才联网。关闭安装弹窗或卸载插件会取消未提交安装。安装后仍需用户开启公众号并扫码。

## 固定发行包

`src/runtime/engine-package.ts` 固定平台、版本、URL、字节数与 SHA-256。复用已发布的 1.0.0 macOS ARM64 ZIP，只提取引擎与许可。更换包时维护者须同步这些字段，不从远程 latest 元数据接受任意程序。未来迭代可改为独立引擎包，不需下载标准插件内容。

## 提交与回退

HTTPS 下载只接受 GitHub 及明确列出的附件主机，限制重定向、大小、连接空闲时间与总安装时间。解压前核对完整摘要，限定提取路径和总解压量；版本元信息、关键文件、Node 版本及服务脚本语法验证成功后，提交到随机版本目录并原子切换本库指针。失败清除暂存文件，不改旧指针和引擎，不触碰共享数据库、登录或订阅。

同一插件目录使用目录锁互斥；异常退出残留锁需关闭 Obsidian 后手动清理。旧版本目录暂时保留，避免删除仍被运行进程引用的文件；没有实现自动垃圾回收或自动更新。旧的手动 engine/ 仍兼容。普通启动、状态检查、RSS 刷新不调用下载器。安装完成不终止或切换已运行的共享采集实例；下次创建进程才使用当前选择。

## 验证与限制

通过现有 Vitest 框架覆盖无自动下载、成功提交、摘要不符、路径穿越、校验失败回退、取消/卸载、重复点击、跨实例锁和不支持平台。另用真实 1.0.0 GitHub 发行包在临时目录实测下载、解压、Node 版本和脚本语法验证；临时数据随验证删除。

当前仅支持 macOS Apple Silicon。用户点击下载可执行依赖仍涉及社区开发者政策，官方适用边界未确认。GitHub Release 发布不等于市场审核通过。
