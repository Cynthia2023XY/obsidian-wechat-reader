# WeChat Reader 1.0.0

- 公众号图片改为阅读时直接从微信 HTTPS 图片 CDN 加载，采集只保存正文和图片来源，避免持续积累大量图片文件。
- 主动归档时下载图片为笔记库附件，保留离线归档能力；阅读图片需要联网，远程失效时可查看原文。
- 兼容历史文章图片来源，RSS 输出远程图片链接；增加带数据库备份和清单的历史图片清理工具，默认只预览。
- 保留 0.4.0 的聚合阅读、缓存管理和订阅功能。

升级说明：公众号用户需同时更新完整安装包中的 engine/，重载插件。更新不会自动删除历史图片；手动清理前须停止采集程序。普通 RSS/Atom 保持原有图片行为。完整安装包面向 macOS Apple Silicon。
