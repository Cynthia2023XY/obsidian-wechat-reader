# WeChat Reader 1.2.0

## 统一订阅管理

- 阅读器“订阅源”旁和插件设置中的“管理订阅”打开同一个窗口。
- 支持按名称、分组和链接搜索，按“全部 / 订阅中 / 已暂停”筛选，统一添加订阅、导入 JSON/OPML 和导出 JSON。
- 名称、类型、分组和状态使用紧凑列表；点击名称展开只读链接与刷新间隔。公众号原文链接明确标为恢复用途。
- 每个来源提供设置及更多操作；公众号设置新增当前笔记库分组编辑。

## 暂停、恢复与移除

- “暂停自动更新”保留侧栏来源入口，可随时恢复。
- “移除订阅”确认后从本库来源列表隐藏，保留历史文章、已读、收藏、归档和缓存。重新添加相同来源可恢复入口。
- 公众号移除会停止本机共享采集，确认窗口会提示其他笔记库也会停止自动更新。本库移除标记不会被共享快照覆盖。
- 移除后，历史文章仍显示原来源名称；订阅配置和 OPML 导出排除已移除来源。
- 公众号设置中的原有“取消订阅”仍保留来源入口；需要从侧栏隐藏时请使用“移除订阅”。

## 升级说明

覆盖更新 `main.js`、`manifest.json` 和 `styles.css`，重新加载插件。已有设置、历史缓存、阅读状态和归档保留。

公众号引擎没有升级；已有兼容引擎可继续使用。按需安装器仍固定使用已验证的 1.0.0 引擎包。完整 ZIP 仅面向 macOS Apple Silicon；GitHub 发布不代表社区目录审核通过。

订阅管理已由用户在正式库体验并确认；本次版本升级后将重新部署构建产物，不将产物复制视为重载实测。
