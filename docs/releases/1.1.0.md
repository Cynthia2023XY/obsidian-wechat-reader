# WeChat Reader 1.1.0

## 可选公众号引擎按需安装

- 普通 RSS/Atom 安装即用，不下载、不启动公众号引擎。
- 设置页和侧栏菜单新增“安装公众号引擎”。安装前显示来源、版本、约 45.5 MiB 下载量及保存位置，用户确认后才联网下载。
- 下载固定版本并验证 SHA-256，解压后检查 Node 运行环境。支持进度、取消、失败重试和重新安装修复。
- 引擎采用独立版本目录和原子指针切换，失败保留原有引擎；不替换订阅、阅读记录或归档。正在运行的共享采集实例继续原任务，下次新启动使用安装版本。
- 保留手动完整包安装方式；中英文安装说明同步更新。

## 升级与支持范围

先更新标准插件文件。公众号引擎缺失时，可在“设置 → WeChat Reader → 公众号引擎（可选）”确认安装；安装完成后再启用公众号并扫码。已有兼容引擎可继续使用，无需重复安装。

插件版本为 1.1.0，安装器仍固定使用已验证的 **1.0.0 引擎包**，不查询 latest，不在后台安装或更新。当前仅支持 macOS Apple Silicon。重新安装会保留旧目录，额外占用约 150 MiB。无法访问 GitHub 时可使用本 Release 的完整 ZIP 手动安装。

用户主动下载可执行依赖的社区政策适用边界尚未获官方确认；GitHub 发布不代表社区目录审核通过。

## 验证

81 项插件测试、25 项采集集成测试、代码规范、类型检查及安装包回归通过。真实引擎下载流程已在临时目录验证，安装入口和确认弹窗已在 Obsidian 测试库检查。
