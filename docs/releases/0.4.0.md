# WeChat Reader 0.4.0

- Browse articles across all feeds directly from All / Unread / Read / Starred.
- Show 50 articles initially and load 50 more at a time, while counts include all matching articles.
- Select a single feed from the collapsible feed navigation; each article shows its source.
- Keep each list’s loaded count and scroll position during the current view session.
- Freeze the currently displayed articles for reader navigation, preserving the reading queue when articles become read or feeds refresh.
- Restore focus to the last article, a nearby article, or the empty-list heading when the reader closes.

顶部“全部文章 / 未读 / 已读 / 收藏”现在直接展示跨来源文章，默认显示 50 篇，可按需继续加载。展开“订阅源”可单独浏览某个来源，切换入口保留当前视图内的加载数量和滚动位置。

公众号用户首次安装或从 0.3.0 之前的版本升级时，需要安装 macOS Apple Silicon 完整包中的 `engine/`；标准插件文件不会自动更新采集服务。已安装 0.3.0 或更新完整包的用户无需为本次改造替换 `engine/`。升级时请保留 `data.json` 和 `cache/`。

Validation: 71 plugin tests, lint, TypeScript checks and production build; Obsidian 1.14.5 smoke checks for aggregate lists, 50-to-100 pagination, favorites and feed selection. The full package is additionally checked in an isolated local-data directory.
