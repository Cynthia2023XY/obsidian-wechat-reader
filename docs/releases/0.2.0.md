# WeChat Reader 0.2.0

RSS/Atom 与微信公众号阅读、订阅迁移和省电运行更新。

- 新增文章、订阅源、分组和全局标记已读，支持批量撤销与已读筛选。
- 失败文章的提示页可自动已读，采集状态与阅读状态独立。
- 默认采用公众号省电模式，到期启动本机采集服务，任务结束后空闲退出；缓存正文和图片可离线阅读。
- 公众号身份与公开原文链接随笔记库配置保存，重新扫码后可恢复订阅。
- 设置中可查看、复制全部订阅链接，并导入或导出统一 JSON 配置。
- 刷新间隔以小时配置；阅读弹窗默认 720px，可在 480～1000px 之间调整。
- 侧栏背景跟随原生主题。

## 安装

普通 RSS/Atom：将 `main.js`、`manifest.json`、`styles.css` 放入笔记库 `.obsidian/plugins/wechat-reader/`，在第三方插件中启用。

微信公众号：下载 `wechat-reader-0.2.0-macos-arm64.zip` 并复制完整 `wechat-reader/` 目录，保留 `engine/`。升级时保留原来的 `data.json` 和 `cache/`。完整包随附 Node 运行时，不会自动安装依赖。

完整包仅支持 macOS Apple Silicon；需要 Obsidian 1.14.4 或更新版本，不支持移动端。公众号需微信读书扫码授权，受上游登录、验证及文章可用性影响。新电脑恢复订阅后重新拉取近期文章；完整历史需另行迁移本机共享数据。
