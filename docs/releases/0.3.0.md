# WeChat Reader 0.3.0

- Stop automatically collecting old WeChat articles. Fetch a page of older articles manually from the subscription menu.
- Keep articles discovered later with an older publication date read after using Mark all as read. Explicit unread choices are preserved.
- Preview and clean shared WeChat article content and images by date, while protecting known vault bookmarks and archived articles.

**WeChat users must install the updated `engine/` folder from `wechat-reader-0.3.0-macos-arm64.zip` alongside the plugin.** Standard Obsidian release assets do not update the companion engine. Close other vaults and let the old companion exit before reloading the updated plugin. Ordinary RSS and Atom do not require the companion.

公众号用户需要从 macOS Apple Silicon 完整包安装新版 `engine/`；仅更新 Obsidian 标准插件文件不会更新采集服务。清理共享缓存会影响其他笔记库和本机 RSS 的离线正文，请先查看预览并确认。
